# Esimde — маңызды оқиғалар туралы еске салу жүйесі

Атауы қазақтың «есімде» сөзінен шыққан — «ұмытпаймын, есімде сақтаулы» деген мағынада.

Пайдаланушыларға маңызды оқиғаларды (туған күндер, емтихандар, университет тапсырмалары,
кездесулер, жұмыс тапсырмалары, мерекелер, жеке оқиғалар) жоспарлауға, күнтізбеде көруге
және белгіленген уақытта еске салу алуға мүмкіндік беретін веб-қосымша.

Интерфейс толығымен қазақ тілінде. Әр пайдаланушының жеке аккаунты бар, ол тек өз оқиғаларын көреді.

## Мүмкіндіктер

- Тіркелу, кіру, шығу; құпиясөздер хештеледі; әр пайдаланушының деректері бөлек.
- Басты бет: 4 статистикалық карточка, алдағы оқиғалар, жақын еске салулар, соңғы хабарландырулар.
- Оқиғаларды қосу, өңдеу, жою (растау терезесімен), орындалды деп белгілеу.
- Іздеу, санат/маңыздылық/күй бойынша сүзу, күні бойынша сұрыптау, беттеу.
- FullCalendar күнтізбесі: айлық, апталық, күндік көрініс; күнді басқанда оқиға қосу.
- Еске салу: APScheduler фондық тапсырмасы + қосымша ішіндегі Toast + браузерлік Notification API.
- Санаттар (түсі мен иконкасы бар) және Chart.js диаграммасы.
- Баптаулар: уақыт белдеуі, күн форматы, әдепкі еске салу, браузерлік хабарландырулар.
- Жеке кабинет: аты, email, оқиғалар статистикасы.
- Responsive дизайн: компьютер, планшет, телефон.

## Технологиялар

| Бөлік | Технология |
|---|---|
| Backend | Python 3.10+ (3.14-те тексерілген), Flask 3 |
| Деректер базасы | SQLite (`sqlite3` стандартты модулі, параметрленген сұраныстар) |
| Жоспарлаушы | APScheduler 3 (`BackgroundScheduler`) |
| Қауіпсіздік | Flask-WTF (CSRF), Werkzeug (құпиясөз хештеу) |
| Frontend | HTML5, CSS3, JavaScript (ES2017), Bootstrap 5.3, Bootstrap Icons |
| Күнтізбе / графиктер | FullCalendar 6, Chart.js 4 |
| Уақыт белдеулері | `zoneinfo` + `tzdata` |
| Тесттер | pytest |

валидация мен көмекші функциялар жеке модульдерде. Бұл `app.py`-ды шағын әрі түсінікті етеді.

## Орнату және іске қосу (Windows)

### 1. Python орнату

Python 3.10 немесе жаңарағы қажет: <https://www.python.org/downloads/>.
Орнату кезінде **«Add python.exe to PATH»** белгісін қойыңыз. Тексеру:

```powershell
python --version
```

### 2. Виртуалды орта құру

Жоба папкасында (PowerShell немесе cmd):

```powershell
cd important_events
python -m venv .venv
.venv\Scripts\activate
```

### 3. Тәуелділіктерді орнату

```powershell
pip install -r requirements.txt
```

### 4. Деректер базасы

Бөлек әрекет қажет емес: бірінші іске қосқанда `instance/events.db` файлы мен барлық кестелер
автоматты түрде жасалады. Қаласаңыз, демо деректерді қосыңыз:

```powershell
python seed_demo.py
```

(кіру: `demo@mail.kz` / `demo123`)

### 5. Серверді іске қосу

```powershell
python app.py
```

### 6. Браузерде ашу

<http://127.0.0.1:5000> мекенжайын ашыңыз → «Тіркелу» → жеке Dashboard ашылады.

### Тесттерді іске қосу

```powershell
python -m pytest
```

### SECRET_KEY (міндетті емес)

Әдепкі бойынша кілт бірінші іске қосқанда `instance/secret_key` файлында кездейсоқ жасалады
(ол git-ке қосылмайды). Өз кілтіңізді беру үшін:

```powershell
$env:SECRET_KEY = "өте-ұзын-кездейсоқ-жол"
python app.py
```

## Еске салу мүмкіндіктері

* **Бірнеше еске салу** — бір оқиғаға: 10 мин, 30 мин, 1 сағат, 1 күн, 1 апта бұрын және өз уақыты.
* **Кейінге қалдыру** — еске салу келгенде «⏰ 10 мин» / «1 сағат» батырмалары (сайтта, Telegram-да, push-та).
* **Қайталанатын оқиғалар** — күн / апта / ай / жыл сайын. Оқиға өткен соң немесе «Орындалды» басылғанда
  келесі күнге автоматты ауысады, еске салулар қайта жоспарланады; күнтізбеде болашақ қайталанулар көрінеді.
* **PWA** — сайтты телефонның басты экранына қолданба ретінде орнатуға болады; желі жоқта «Офлайн» беті.
* **Web Push** — еске салулар сайт жабық болса да телефонға/компьютерге келеді (HTTPS қажет; iPhone-да —
  алдымен басты экранға қосу, iOS 16.4+). VAPID кілттері `instance/` ішінде автоматты жасалады.

## Хостинг (Railway) — телефоннан ашу үшін

1. **GitHub**: жаңа репозиторий жасап, `esimde_github` папкасындағы барлық файлдарды жүктеңіз
   (`.env`, `instance/`, `.venv/` жүктелмейді — олар құпия/жергілікті).
2. **Railway** → *New Project* → *Deploy from GitHub repo* → репозиторийді таңдаңыз.
   Іске қосу командасы `railway.json`-да бар: `python serve.py` (waitress, бір процесс).
3. Сервиске **Volume** қосыңыз, *Mount path*: `/data`.
4. *Variables* бөліміне қосыңыз:
   ```
   DATA_DIR=/data
   TELEGRAM_BOT_TOKEN=<BotFather токені>
   TELEGRAM_BOT_USERNAME=<бот username>
   ```
5. *Settings → Networking → Generate Domain* — `https://….up.railway.app` мекенжайы шығады.
   Оны телефонда ашып, тіркеліп, **Баптаулар → Push-ты қосу** және **Телефонға орнату**.

Маңызды: бір бот токенімен бір ғана сервер жұмыс істеуі керек — хостинг іске қосылғанда
жергілікті `python app.py`-ды токенмен қатар қоспаңыз (Telegram 409 қатесі).
Хостингтегі база жергіліктіден бөлек — онда қайта тіркелу керек.

## Telegram бот (@EskeSalKzBot)

Еске салулар Telegram-ға да жіберіледі — сайт жабық болса да (сервер жұмыс істеп тұруы керек).

1. Жоба түбіріндегі `.env` файлын ашып, BotFather берген токенді қойыңыз:
   ```
   TELEGRAM_BOT_TOKEN=1234567890:AAH...
   ```
   `.env` репозиторийге қосылмайды (`.gitignore`). Үлгі — `.env.example`.
2. Серверді қайта іске қосыңыз: `python app.py`.
3. Сайтта **Баптаулар → Telegram-ды қосу** басыңыз → ашылған ботта **Start** басыңыз.

Бот мүмкіндіктері: еске салу хабарламасы «✅ Орындалды» батырмасымен, `/upcoming` — алдағы оқиғалар,
`/stop` — ажырату, `/help` — көмек. Байланыстыру сілтемесі бір реттік және 15 минут жарамды.
Бот long polling режимінде жұмыс істейді, сондықтан HTTPS немесе webhook қажет емес.
Бір бот токенімен бір ғана сервер процесі жұмыс істеуі керек (әйтпесе Telegram 409 қатесін береді).

## Еске салу механизмі қалай жұмыс істейді

1. Пайдаланушы оқиға қосып, еске салу режимін таңдайды (10 мин, 30 мин, 1 сағат, 1 күн немесе өз уақыты).
2. Сервер еске салудың нақты уақытын пайдаланушының уақыт белдеуін ескеріп **UTC** форматында
   есептейді және `events.reminder_datetime` өрісіне жазады.
3. `reminder_service.py` ішіндегі APScheduler әр 20 секунд сайын `process_due_reminders()` функциясын шақырады.
4. Функция уақыты келген, әлі жіберілмеген (`reminder_sent = 0`), орындалмаған оқиғаларды табады.
5. Әр оқиға атомарлы түрде иеленіледі:
   `UPDATE events SET reminder_sent = 1 WHERE id = ? AND reminder_sent = 0`.
   Егер өзгерген жол саны 0 болса, оны басқа процесс өңдеп қойған, сондықтан қайталау болмайды.
   Қосымша қорғаныс ретінде `notifications` кестесінде `UNIQUE(event_id, scheduled_for)` шектеуі бар.
6. `notifications` кестесіне қазақша мәтіні бар жазба қосылады, мысалы:
   «Еске салу: «Математика емтиханы» оқиғасына 30 минут қалды!»
7. Браузер әр 15 секунд сайын `/api/notifications/pending` сұрайды, хабарламаны Toast ретінде және
   (рұқсат болса) браузерлік хабарландыру ретінде көрсетеді, содан кейін `/api/notifications/ack`
   арқылы растайды. Бір хабарлама екінші рет көрсетілмейді.

**Ерекше жағдайлар:**

| Жағдай | Әрекет |
|---|---|
| Сервер қайта іске қосылды | Жоспар базада сақталған, іске қосылған сәтте бірден тексеріледі |
| Сервер тоқтап тұрғанда еске салу уақыты өтті, оқиға әлі алда | Бірден жіберіледі, күйі «кешіктірілген» (`late`) |
| Оқиғаның өзі де өтіп кетті | Жіберілмейді, күйі «өткізіліп алынды» (`missed`) |
| Оқиға орындалды деп белгіленген | Еске салу жіберілмейді |
| Еске салу уақыты өңделді | `reminder_sent` 0-ге қайтарылады, жаңа уақытқа қайта жоспарланады |
| Браузерлік рұқсат жоқ | Еске салу қосымшаның ішінде Toast ретінде көрсетіледі |

> Еске салу сервер жұмыс істеп тұрған кезде өңделеді. Хабарламаны көру үшін қосымша браузердің
> кез келген қойындысында ашық тұруы керек (сервер push-хабарландыру жібермейді). Егер бет кейін
> ашылса, жіберілген бірақ әлі көрсетілмеген хабарламалар сол сәтте көрсетіледі.

## Жиі кездесетін қателер

| Мәселе | Шешімі |
|---|---|
| `'python' is not recognized` | Python-ды PATH-ке қосып қайта орнатыңыз немесе терминалды қайта ашыңыз |
| `.venv\Scripts\activate` орындалмайды («running scripts is disabled») | PowerShell-де: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, немесе cmd қолданыңыз |
| `ModuleNotFoundError: No module named 'flask'` | Виртуалды орта белсенді екенін тексеріп, `pip install -r requirements.txt` орындаңыз |
| `ZoneInfoNotFoundError` | `pip install tzdata` (requirements.txt ішінде бар) |
| `Address already in use` / порт бос емес | Басқа портта іске қосыңыз: `$env:PORT=5001; python app.py` |
| Беттің стилі / күнтізбе жүктелмейді | Bootstrap, FullCalendar, Chart.js CDN арқылы жүктеледі — интернет байланысын тексеріңіз |
| «Қауіпсіздік токенінің мерзімі өтті» | Бетті жаңартып, әрекетті қайталаңыз (сервер қайта іске қосылғанда болуы мүмкін) |
| Браузерлік хабарландыру шықпайды | Баптаулар бетінде рұқсат күйін тексеріңіз; Windows-та «Фокус» режимі өшірулі болсын |
| `database is locked` | Базаны басқа бағдарламада (DB Browser т.б.) ашық қалдырмаңыз |
| Барлық деректерді тазалау | Серверді тоқтатып, `instance/events.db` файлын жойыңыз — келесі іске қосқанда жаңа база жасалады |
